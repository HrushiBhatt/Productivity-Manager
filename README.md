# ☕ Brew Focus - Pomodoro Timer

A beautiful, interactive coffee-themed Pomodoro timer with a pure black background and smooth animations.

## ✨ Features

- **Visual Coffee Mug**: Watch the coffee drain as time passes
- **Pure Black Theme**: Easy on the eyes, perfect for focus
- **Animated Steam**: Steam rises when timer is running
- **Progress Ring**: Visual circular progress indicator
- **Presets**: 5, 10, 25, and 50-minute quick options
- **Custom Timer**: Set any time in minutes and seconds
- **Statistics**: Track sessions, focus time, and streaks
- **Audio Alert**: Pleasant chime on completion
- **Browser Notifications**: Get notified when done
- **Keyboard Shortcuts**: Quick controls
- **Settings Modal**: Toggle sound and notifications
- **Responsive**: Works on desktop and mobile

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `R` | Reset |
| `1-4` | Presets |
| `Esc` | Close modal |
